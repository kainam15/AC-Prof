数据来源与分析口径

    配置状态 ok 只描述已写入的正式窗口，不证明整个实验计划已完成；完成度仍以原始 run state 和 audit 验收为准。

    原始 CSV 保持完整。CPU package + GPU 总能量仅覆盖成功请求窗口；CPU 配置只计 package，GPU 配置须同时具有 package 与所选 GPU 的记录。没有加入 DRAM、启动或 idle 时段，也不等同于整机墙插能耗。

    窗口总能量按每行 energy/request × 实际请求数求和；energy/request 按请求数加权。其他均值等权汇总窗口，峰值取最大值。Cold start 按启动时间去重；缺少启动身份时仅接受一致的复用值。

    QPS 仅展示显式记录的 request/s；不会从 samples/s 推断。颜色与 frontier 按当前用途下已核验的条件分组；不兼容和证据不足只保留绝对值、原始证据与散点。未提供 CI 或重新计算合并请求分位数。
