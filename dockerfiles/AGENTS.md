# 镜像构建约束

- 保持环境、模型计划、业务代码分层；依赖层不复制业务代码。模型权重由主机 Model Store 管理并只读挂载，模型文件选择规则与最终代码分开计算指纹。
- 新依赖组合在目标 Python/CUDA 环境解析和验证；精确依赖锁与已安装版本清单用途不同，不将清单当作可复现安装锁。
- 影响内容的构建参数、下载策略或文件必须进入对应指纹；构建和验证遵循[运行兼容契约](../docs/models/runtime.md#构建复用和验证)。
- Hugging Face 令牌仅用于主机认证与 Model Store 下载，不传入 Docker 构建或推理容器，不写入日志；补采保留原实验不可变 image ID 的语义。
